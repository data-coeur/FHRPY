Everything in the FHRPY project must be **in English** — code, comments,
identifiers, documentation, commit messages, READMEs. The **only** exception:
replies/comments on GitHub issues may be in French (the human writes in French).

**Why:** the toolbox is meant to be public and international (like FHRMA).

**How to apply:** write all repo artifacts in English; when commenting on an
issue for the human, French is acceptable. See [[fhrpy-project]].
